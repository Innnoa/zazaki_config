## AAR Four Questions

Before claiming a non-trivial task complete, check each:

1. Did this reveal a reusable new pattern (including verification steps worth reusing)?
2. Did this reveal new high-cost gotchas?
3. Did this reveal missing rules?
4. Did this reveal outdated rules?

### Minimum Requirements

- All questions must be checked, not skipped.
- If all answers are "no", explicitly state: "No new rules or gotchas from this task."
- If any answer is "yes", decide: promote to formal rules/workflows/references, or stage in AAR_INBOX.

### Red Flags — Stop Immediately

- Thinking "skip AAR this time"
- Claiming completion without scanning AAR
- Writing a gotcha only into references/ without updating the task path
- Fixing the same bug class twice without updating rules
