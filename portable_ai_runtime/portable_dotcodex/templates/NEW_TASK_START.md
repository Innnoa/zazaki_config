# New Task Start Template

把下面内容复制到新会话里，再按实际任务替换占位内容。

```text
这是 /home/zazaki/.codex 下的一个新任务，不延续上一个任务。

先读：
1. AGENTS.md
2. 先把 CURRENT_TASK.md 刷新为这个新任务
3. AI_GUIDE.md 的固定概要区和最新 READ_ANCHOR 之后的增量内容
4. DECISIONS.md 中与本任务相关的条目
5. 本次直接相关的 1 到 3 个文件

本次目标：
- [要完成的结果]

范围：
- [允许修改的文件或模块]
- [明确不改的内容]

验收标准：
- [标准 1]
- [标准 2]

约束：
- [兼容性 / 安全 / 性能 / 成本约束]

验证：
- [要执行的命令或检查方式]

交付：
- 代码或文档改动
- 实际验证结果
- 残留风险或未覆盖项
```

最小用法：

- 小任务可以省略“范围”或“约束”中的空项。
- 任务跨轮但不是续做旧任务时，先更新 `CURRENT_TASK.md` 再启动新会话。
- 如果任务需要更强治理、冻结需求和计划，首行写 `$vibe`，再粘贴其余内容。
