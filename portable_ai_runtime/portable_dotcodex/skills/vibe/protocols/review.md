## Review Protocol

本文件描述 `vibe` 路径下的 review / quality gate。

### Review Focus

- 行为回归
- 边界条件
- 验证缺口
- overclaim 与 host-truth mismatch
- requirement / plan / delivery 之间是否仍可追溯

### Minimum Gate

- 关键 claim 有对应证据
- 无新增第二 requirement / plan surface
- cleanup 义务已完成或已明确列为未完成项

### Output Rule

- findings 优先
- 没有 finding 时，明确写“未发现问题”，再补残留风险
