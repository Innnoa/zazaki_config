# 动机与体验弧线层

## Peak-End Rule（峰终定律）

用户对体验的评价不由平均值决定，而由情感最强烈的时刻（Peak）和结束时的感受（End）决定。

检验：用户体验的"正峰值"在哪里？是否刻意设计过？完成核心任务后的"结尾体验"是否让人愉悦？

- 一次糟糕体验需要 3-5 次好体验才能抵消 → 削减负峰值比创造正峰值更重要
- 正峰值：注册后个性化欢迎、首次使用"啊哈时刻"、客服瞬间解决问题
- 完美结尾：购买完成 → "预计周五到达！"而非"订单已提交"；订阅取消 → "您的数据保留 30 天"
- 服务器 500 → 至少用幽默 404 页面替代白屏

## Serial Position Effect（序列位置效应）

用户更容易记住列表的第一项（首因效应）和最后一项（近因效应），中间的容易被遗忘。

检验：导航的第一个和最后一个位置放了最重要的项目？关键 CTA 在页面视觉终点？下拉菜单推荐选项在第一项？

- 导航：最重要放最左（首因）和最右（近因），次要放中间
- 定价页：企业版放最左、基础版放最右 → 先看贵的，便宜的显得超值
- 下拉菜单第一项 = 最常用/推荐；最后一项 = "其他/自定义"
- 落地页：开头抛核心价值 → 中间详情 → 结尾 CTA

## Goal-Gradient Effect（目标梯度效应）

越接近目标，完成动力越强。看到进度条快满时用户会加速。

检验：多步骤流程是否显示了进度（当前步/总步数）？是否让用户感觉"已经开始了"（预填/默认值）？最后一步是否做了减法？

- 进度条/步骤指示器 = 必须显示
- 人为制造"已开始"：注册时预填已知信息 → 视觉上已完成一部分
- "Step 2/3" 比 "进度 66%" 更有驱动力
- 接近完成时：去除多余确认、预填信息、展示"完成后你将获得..."
- 咖啡实验：12 格已盖 2 格 > 10 格空白，完成率显著更高

## Flow（心流）

用户完全沉浸于活动时达到的最佳体验状态——高度专注、时间感消失、操作变成本能。

检验：有没有不必要的弹窗/打断？每个操作是否有即时反馈？是否有"不打断"的路径（快捷键盘、自动保存）？

- 心流条件：明确目标 + 即时反馈 + 挑战与技能匹配 + 不被打断 + 控制感
- 心流敌人：弹窗打断（用 toast 替代）、加载等待（<400ms Doherty Threshold）、决策打断（自动保存+可撤销）
- 内容消费心流：读完自动推荐下一篇、视频结束自动播放下一个
- 创作工具心流：Figma 自动保存无打断、Notion 的 `/` 命令面板不用摸鼠标
- 难度曲线：随着用户技能提升逐步增加挑战（游戏设计教科书）
