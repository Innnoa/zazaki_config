# 认知记忆层

## Miller's Law（米勒定律）

人脑一次只能在短期记忆中保持 7±2 个信息块。

检验：导航 ≤ 7 项？长列表是否分了组？用户需要同时记住的信息 ≤ 5 个？

- 实际安全数字是 4-5 个组块，不是 7
- 结构化（chunking）比死守数字更重要
- 导航、表单字段、列表项、步骤指示器都受此约束

## Cognitive Load（认知负荷）

界面占用的心智资源，越少越好。降低外在负荷是 UX 核心目标。

检验：用户能在 5 秒内理解页面是做什么的吗？每个元素存在都有充分理由？

- 三种负荷：内在（任务难度）、外在（界面设计强加）、相关（学习理解）
- 降低外在负荷 = UX 核心目标
- 渐进式披露：先核心信息，高级功能折叠
- 识别 > 回忆：下拉选择 > 手动输入，图标+文字 > 纯图标
- 这是所有 UX 法则的总调度——其他法则都在降低某种认知负荷

## Chunking（分块）

把零散信息按意义重组成更大的信息块，突破 Miller's Law 的 7±2 限制。

检验：长列表是否用标题/分类分组？表单字段是否按语义拆段？电话号码/卡号是否有视觉分段？

- 电话号码 138-1234-5678（3 组块替代 11 碎片）
- 表单分组：账户信息 / 安全 / 个人资料 / 地址
- 导航分组：公司 / 资源 / 支持
- 分组方式：语义分组、视觉分组（Card）、序列分组（Step 1→2→3）、字母/数字分段

## Zeigarnik Effect（蔡格尼克效应）

未完成的任务比已完成的更让人难忘——驱使用户去完成。

检验：进度条/完善度是否能温和激励用户完成？未完成提示数量是否合理（不制造焦虑）？

- 资料完善度"75%"→ 驱使用户继续填写
- 试用到期提醒 → 提升付费转化
- 游戏化："还差 20 积分升级"→ 继续使用
- 过度提醒 → 焦虑，控制在 3 个以内

## Paradox of the Active User（活跃用户悖论）

用户从不看教程，直接上手乱试。设计必须让"乱试"也能成功。

检验：没有引导教程，新用户能在 1 分钟内完成核心任务吗？

- 放弃长篇引导 → 拥抱空状态教学（"还没有内容？点击 + 创建第一条"）
- 即时教学 > 预设教程：在用户需要时才提示
- 功能可发现性：常用功能直接可见，高级功能按需展示
- 防错 + 可撤销 > "你应该先看教程"

## Selective Attention（选择性注意）

用户只看与当前目标相关的东西，其他全部被大脑过滤掉。

检验：页面上的"注意力竞争者"是否过多？用户能在扫读状态下抓住核心信息？

- 用户是扫读模式，不是阅读模式
- 标题层级引导扫读；大段文字被主动忽略
- 横幅盲视：用户已学会忽略"看起来像广告"的东西
- 关键信息在需要时才出现，不要信仰首页能展示一切

## Working Memory（工作记忆）

工作记忆容量小（4±1 组块）、时间短（10-20秒）、极易被干扰。

检验：用户是否需要记住上一页的信息才能在当前页操作？多步骤流程中前几步的关键信息在后续步骤中是否可见？

- 不要让用户跨页面记忆信息（订单号自动传递）
- 表单验证失败 → 保留已输入内容，不清空
- 提供"外部记忆"：自动保存草稿、搜索历史、对比视图
- 一次打断 → 工作记忆清空 → 用户需要重载

## Cognitive Bias（认知偏差）

用户不是理性的，每个判断都带着系统性偏差。

检验：定价是否用锚定效应（先展示高价再展示目标价）？关键信息表达框架是否提升了转化？

- 锚定效应：原价 ¥2999 → 现价 ¥999 比原价 ¥1499 → ¥999 更有吸引力
- 框架效应："成功率 90%" > "失败率 10%"
- 损失厌恶："立刻购买，否则失去 20% 折扣" > "获得 20% 折扣"
- 从众效应："已有 10,000+ 团队在使用"
- 现状偏误：好的默认设置至关重要（用户不会去改）
- 宜家效应：让用户参与创建的内容，TA 们估值更高
