## 工具差异

只记录已经真实观察到、并且会影响执行质量的工具差异，例如：

- 不同 harness 的上下文压缩差异
- 不同工具的 hook、生效时机或输出差异
- 会直接影响路由、验证、审查或写入位置的行为差异

## 示例锚点

- 非 git 目录下无法提供 `git diff` 级别的变更证据，这会限制“只修改了哪些文件”的严格审查能力。
- 当前环境同时存在两层 LSP 相关能力：OpenCode 原生 LSP 更适合拿诊断与显式 LSP 查询证据，`serena` 更适合拿符号级、跨文件、结构化语义证据；治理规则里不应把两者混写成同一种工具。
- 当前环境下，把 subagent 派发 prompt、目标、边界、约束与输出要求统一为英文，比中英混用更稳定；主 agent 对用户的汇报与治理文档继续保持中文即可。
- 某些工具或配置改动只有在 refresh / reactivate / restart 后才会变成真实运行事实；这里只保留该锚点，详细规则统一放在 `references/ai/runtime-refresh-rules.md`。
