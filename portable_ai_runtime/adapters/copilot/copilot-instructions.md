# Copilot Instructions — AI Governance Runtime

安装路径：`.github/copilot-instructions.md`

## 核心规则
GitHub Copilot 会自动读取此文件作为 AI 指令。
首先阅读 AGENTS.md 了解完整的路由和验证规则。

## 任务路由
- Bug 修复 → systematic-debugging → workflows/ai/fix-and-review.md
- 新功能 → brainstorming → workflows/ai/plan-and-implement.md
- 代码审查 → workflows/ai/fix-and-review.md

## 验证
- 任务完成前必须验证
- 结论基于证据，禁止猜测
- 提交前检查代码质量

## 会话管理
- 新任务重读入口
- 长会话压缩非必要细节
