# Governance Docs

本目录用于区分 portable pack 的**运行态治理文件**与**建设历史文档**。

## Active Runtime Governance

当前真正作为运行时权威源的内容在：

- `AGENTS.md`
- `rules/ai/`
- `workflows/ai/`
- `references/ai/`
- `state-templates/`

这些文件定义当前 portable pack 的正式治理规则、工作流、样本参考和状态模板。

## Archived Build History

建设历史保存在：

- `docs/governance/history/`

这些文件用于说明这套治理系统是如何逐步建立的，包括设计文档与阶段性实施计划。

历史文档只作参考，不是 live source of truth。
