## Think Protocol

本文件描述 `vibe` 在编码前的思考与研究纪律。

### Use This Layer For

- 澄清需求与边界
- 判断是否需要补读设计、历史决策或验证规则
- 决定 internal grade：`M`、`L`、`XL`
- 判断是否允许 specialist help 或 child-governed delegation

### Required Output Shape

- goal
- deliverable
- constraints
- acceptance criteria
- non-goals
- assumptions
- verification intent

### Guardrails

- 缺关键事实时先补事实，不要直接实现
- 不能因为问题看起来“小”就跳过 requirement / plan 冻结
- 推断必须和仓内证据或用户明确输入分开表述
