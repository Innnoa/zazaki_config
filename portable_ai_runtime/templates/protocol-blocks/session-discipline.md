## Session Discipline

Every new task — even the N-th round in the same session — must re-read the entry point and re-match the routing table.

1. Re-read the top-level entry file (AGENTS.md / SKILL.md).
2. Re-match against Common Tasks routing.
3. Re-read all files listed under the matched route.

Check: "Do the files I actually read match exactly what the routing table lists for this task type?"
If there is any difference (fewer, more, from memory), go back and re-route.

### Explicitly Rejected Excuses

- "This is just a small addition, not a new task"
- "I already read those files"
- "Do it first, fill in routing later"
- "I should still remember after compression"
