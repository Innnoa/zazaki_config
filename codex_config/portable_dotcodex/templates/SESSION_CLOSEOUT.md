# Session Closeout Template

结束当前会话前，先把本轮真实状态补齐，再将下面内容保存为交接摘要或直接发给下一轮会话。

```text
本轮任务结束，交接如下。

目标：
- [本轮原始目标]

已完成：
- [完成项 1]
- [完成项 2]

未完成：
- [待办项 1]
- [待办项 2]

当前阻塞：
- [无 / 具体阻塞]

相关文件：
- [文件 1]
- [文件 2]
- [文件 3]

实际验证：
- [已执行命令 / 回读检查]
- [未执行但建议补做的验证]

下一会话先读：
1. AI_GUIDE.md 的固定概要区和最新 READ_ANCHOR 之后的增量内容
2. CURRENT_TASK.md
3. DECISIONS.md 相关条目
4. 本轮直接相关文件

残留风险：
- [风险 1]
- [风险 2]
```

使用约束：

- 不复制整段聊天历史。
- 不粘贴整份 diff 或大段日志。
- 只保留下一位执行者真正需要的最小事实集合。
- 如果下一轮不是继续本任务，先覆盖 `CURRENT_TASK.md`，不要让下一轮先复述本摘要。
